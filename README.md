# Gerenciador Financeiro Pessoal (FinControl)

Um sistema completo de gestão de finanças pessoais e pequenos negócios, desenvolvido com foco em precisão, modularidade e experiência do usuário.

## 🏗️ Arquitetura do Sistema
O projeto é dividido em dois componentes principais (monorepo):

- **[Backend](backend/README.md)**: API RESTful construída com Spring Boot, utilizando MySQL e segurança via JWT.
- **[Frontend](frontend/README.md)**: Aplicação web moderna com Angular e Tailwind CSS, focada em visualização de dados.

## 💡 Principais Características
- **Controle Total**: Gerencie despesas, receitas, faturas de cartão e fluxos de caixa.
- **Múltiplos Workspaces**: Isole suas finanças pessoais de seus projetos ou pequenos negócios em ambientes distintos.
- **Segurança de Dados**: Autenticação robusta e proteção de informações sensíveis.
- **Design de Alta Fidelidade**: Interface técnica e minimalista seguindo o estilo "Typographic Brutalism".
