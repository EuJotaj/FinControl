# Gerenciador Financeiro Pessoal - Frontend

Este é o Frontend do sistema de controle financeiro pessoal, desenvolvido com Angular 21 (simulado) e TailwindCSS, como parte da **Fase 1**.

## Pré-requisitos
* Node.js 25.8.1
* npm

## Instruções para Rodar

1. Acesse o diretório do frontend:
   ```bash
   cd frontend
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run start
   ```
4. Navegue para `http://localhost:4200/` no seu navegador. Os dados já estão sendo alimentados por serviços Mock criados localmente com suporte ao RxJS para simular latência de rede.

## Temas (Claro e Escuro)
O sistema suporta alternância de temas, salvando a preferência no `localStorage`. Para testar, clique no ícone de Sol/Lua no Topbar do Dashboard.
