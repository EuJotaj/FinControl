# FinControl Frontend (Dashboard)

Interface moderna e intuitiva do **Gerenciador Financeiro Pessoal**, desenvolvida para oferecer precisão e facilidade no controle de gastos.

## 🚀 Tecnologias
- **Angular 19+**
- **Tailwind CSS**
- **TypeScript**
- **Vite** (Build tool)

## 🎨 Design System
O projeto utiliza o **FinControl Precision**, um sistema de design focado em:
- **Typographic Brutalism**: Interface limpa e direta.
- **Contraste Técnico**: Facilitando a leitura de dados financeiros.
- **Micro-animações**: Para uma experiência de usuário fluida.

## 🛠️ Funcionalidades
- **Dashboard Dinâmico**: Visualização de saldo e faturas.
- **Gestão de Cartões**: Cadastro e visualização de faturas.
- **Workspaces**: Troca rápida entre ambientes (pessoal/negócios).
- **Traduções**: Suporte a múltiplos idiomas (i18n).

## ⚙️ Como Executar
1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm start
   ```
3. O dashboard estará disponível em `http://localhost:4200`.

## Running unit tests

To execute unit tests with the [Vitest](https://vitest.dev/) test runner, use the following command:

```bash
ng test
```

## Running end-to-end tests

For end-to-end (e2e) testing, run:

```bash
ng e2e
```

Angular CLI does not come with an end-to-end testing framework by default. You can choose one that suits your needs.
